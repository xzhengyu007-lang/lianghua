> `qfq = raw × 常数`。这会让日收益波动被系统性放大（中位数 +10.5%，最严重

> 这些数字**不能**作为修正后的结论引用。
>
> 修正路径：`quant_system/adjustment.py` 从 raw + qfq 重建乘法总收益序列；
> `reports/adjustment_rebuild/` 给出同窗口三口径对比。新回测请显式传
> `--adjustment rebuilt`（需要 raw 缓存）。
>

> 重建序列（`data/cache/*_raw.parquet`、`*_tr.parquet`），没有一只 PIT 标的只

> 之前的“116 只退市股缺 raw”结论已过期。剩余限制不是数据缺失，而是**历史的
> 起点**（见「已知限制」）。默认口径仍为 `cached` 以保持历史可复现，
> `cache-audit` 会把它报成 problem。

真实数据、严格避免前视偏差的 A 股日频量化系统：数据采集 → 因子研究 →

## 引用口径（唯一权威，有测试守着）

系统里有**两个不同的东西**：一个是"历史上跑过的默认配置"，一个是"准备部署的配置"。
引用数字前先确认引的是哪一个——§23.82 证明了三段样本外数字有两段落在相位分布的好运侧。

| 口径 | 全期收益 | 2024–2026 | 全期 Sharpe | 全期最大回撤 |
|---|---:|---:|---:|---:|
| **部署口径：混合 + 12% 目标波动** | **+95.87%** | **+26.29%** | **0.902** | **-15.70%** |
| 混合 + 18% | +109.12% | +27.72% | 0.886 | -20.59% |
| 单相位 @18%（旧默认，运气相位） | +192.63% | +43.68% | 1.160 | -21.46% |
| 2024–2026 相位中位 | — | +24.97% | 0.668 | — |
| 2024–2026 最差相位 | — | +9.13% | — | — |

三条规矩：

1. **引用任何单点收益，必须同时给出相位中位与最差相位**（§23.82：20 个合法相位的收益
   跨度是 32–47pp，年度重置并没有消掉这个分布）。
2. **+192.63% 是"某个日历"的长期收益，不是"这个策略"的长期收益。** 三段相位中位复利
   是 +111.6%，混合实测 +109.12%（§23.86）；单相位的高 Sharpe 同样来自那三次好运窗口。
3. **跨脚本比较前先确认分母。** 年表类脚本用 `std(ddof=0)`、引擎 `metrics` 用
   `ddof=1`，Sharpe 差约 0.00025（= `sqrt(1799/1800)`）；另有首日口径（§23.48）
   与切片口径（§23.73）两处同类坑。

这张表由 `tests/test_reference_numbers.py` 对着 `reports/` 逐项核对：**改数字必须先改报告**，否则测试会红。

## 命令

| 命令 | 作用 |
|---|---|
| `download` | 分页下载前复权日线，重叠校验并写元数据 |
| `validate` | 缺失率、重复日期、OHLC 违规、价格非正、僵尸价格 |
| `cache-audit` | 逐文件核对 parquet 与 `meta.json`：行数、起止日期、页数、重叠告警、非正价格、**加法复权检测**；`*_tr.parquet` 也纳入审计（要求与 sidecar meta 行数/起止日期一致）。退出码非零表示缓存不自洽。当前 109 个 qfq 文件会被标为 problem，这是**预期行为**，不是回归；151 个 `_tr` 文件为 0 problem |
| `fingerprint` | 对回测产物（净值、成交、元数据）生成稳定指纹，可与另一次运行逐字段比对；不一致时退出码非零 |
| `audit` | 一键体检：数据质量、研究窗口、行业覆盖、退市候选、最新信号；`problems=[]` 才算通过 |
| `backtest` | 单策略全历史回测，输出 CSV/Markdown/PNG/HTML；`--use-regime` 打开基准趋势开关，`--turnover-cap` 打开组合层换手限制，`--vol-forecast ex_ante` 改用当前篮子协方差估计波动，`--impact-coefficient-bps` 打开平方根冲击成本，`--drawdown-stop` 打开因果回撤熔断，`--target-vol 0.12` 直接指定年化波动目标（决定仓位），`--rebalance-reset year` 让调仓日历与窗口起点无关；`--universe pit` 使用存续+真实退市池 |
| `walkforward` | 训练窗口选参、测试窗口评估，逐窗口审计（`windows.csv` + `audit.csv`）；`--phase-sweep N` 给出调仓相位的 median/worst/best，`--phase-blend` 交易全部相位的平均权重，`--target-vol` 调风险预算 |
| `signal` | 最新收盘目标权重、股数、金额、行业与风险提示；目标权重与回测共用 `normalize_targets`（先截单票 25%、再缩总仓位 95%），`--equity` 按账户总权益定量 |
| `brief` | 一页日常简报：数据健康（在册/退市/停牌分开计）、下一开盘目标篮、事前波动与 beta、持仓集中度，可选接入模拟盘账本给出目标/实际偏差；最新 bar 落后当天超过 5 个交易日会直接告警（§23.69）；输出 `brief.md` / `brief.json` / `brief.html` |
| `paper` | 模拟盘账本：按最新信号下单、登记成交、与券商对账 |
| `compare` | 多策略滚动样本外对比 |
| `bootstrap-ci` | 对 walk-forward 净值做平稳块自助法：给出 CAGR/Sharpe/回撤的 95% 区间，并用配对重采样检验「A 是否真的优于 B」；`--suite` 复现本轮 trend 参数对照 |
| `attribution` | 对已完成的 `backtest`/`walkforward` 目录（`positions.csv` + `equity.csv`）做 Brinson-Fachler 月度行业归因：把相对等权全池的超额拆成行业配置 / 行业内选股 / 交互，残差为 1e-16 量级；`--report-dir` 指向被归因的报告，价格口径沿用全局 `--adjustment` |

全局参数：`--universe {default,broad,pit}`、`--symbols`、`--min-bars`、`--benchmark`。

`pit` 股票池 = 128 只当前宽基 + `data/delisted_manifest.json` 中 140 只真实退市股，
共 268 只（同窗口内至少有一根 K 线的 267 只）。退市股只在仍有个股 K 线的日期
可入选，退市后在最后一根真实 bar 强制清算；因此它是 point-in-time 成员资格，
不是把“未来才知道会退市”的名单提前放进早期横截面。`--universe pit` 可用于
`backtest`、`walkforward`、`compare`、`signal`、`paper` 与 `validate`。

### 研究窗口与复现

`backtest` / `walkforward` / `compare` 在不指定 `--start/--end` 时会自动裁剪到
**95% 横截面覆盖率窗口**，与所有研究报告使用同一口径。这一点很重要：宽基池里的
`sh600837` 有 2017 年起的完整历史，而其余标的 2019 年才有数据；直接取日期并集会
把回测起点拉到 2017 年、股票数只剩 1–25 只，同一命令会得到 +121% 而不是当前基线的 +149.5%。
`tests/test_data.py::test_research_window_ignores_a_single_long_history` 固定了该行为。
CLI 输出会打印 `research window ...` 以便核对。

执行假设

- 信号在**收盘后**生成，订单在**下一交易日开盘**成交（`execution_price=open`）。
- 目标股数在调仓日按开盘权益一次性冻结，日内价格波动不产生额外交易。
- 整手（100 股）、最小订单金额、佣金（含 5 元最低）、印花税（卖出）、过户费、
  滑点（按 bp 计，双向不利）。
- 涨跌停：开盘价触及涨停不可买，触及跌停不可卖；成交量为 0 视为停牌。
  例外：**退市整理期首日不设涨跌幅限制**，开盘价超过标的上限两倍且当日有成交时
  按可成交处理。不这样做的后果是把真实暴跌误判为“跌停卖不掉”，回测会凭空持有
  一个现实中早已清仓的亏损头寸（见 `reports/pit_rebuilt/`）。
- 容量：单日单票成交不超过 20 日均量的 `max_adv_participation`（默认 10%）。
  ADV **只用上一根及更早的 bar**（`volume.shift(1)`），因为订单在当日开盘执行时
  当日成交量还不存在；`adv_includes_today=True` 仅用于复现旧报告。
  该执行层约束本身就起到了分批下单的作用，因此组合层的 `cap_turnover` 默认关闭
  （打开后总收益少 14pp、Sharpe 少 0.05，只换来 1.1pp 回撤改善）。
- 退市：在最后一根真实 K 线的**开盘价**强制清算（减滑点），不留冻结价格仓位。
  用收盘价会是同日前视：退出决定在开盘前已成立，不该用当天收盘价成交。
- T+1：同一标的不可能当日买入又卖出。
- 换手口径：单边成交额 / 平均权益（全区间，不做年化）。
  **walk-forward 的窗口换手按该窗口自己的平均净值计算**；旧版误用了
  从初始资金起算的全历史平均净值，窗口越靠后换手越低（§23.29 / §23.30）。

## 策略

| 名称 | 逻辑 |
|---|---|
| `low_vol_core` | 低波为主（0.8）+ 趋势确认为辅（0.2），趋势在 120 日均线上方才可入选 |
| `low_volatility` | 纯低波 + 趋势过滤 |
| `momentum` | 动量减波动惩罚 + 趋势过滤 |
| `multi_factor` | 动量/趋势/低波加权 |
| `breakout` | 55 日突破、20 日退出 |
| `mean_reversion` | 上升趋势中的 RSI 超卖 |
| `low_vol_plus` | 低波核心 + 可选的额外信号（非流动性、12-1 动量），默认权重 0，等价于 `low_vol_core`；用于检验“第二个信号”，结论见下文 |

所有策略共享：横截面排名、行业上限、`rebalance_days` 最小持有期、
`buffer_rank` 排名缓冲（持仓跌出 `top_n × buffer_rank` 才换出）。
可选 `rebalance_on="month_end"` 把固定周期换成月末日历（研究显示更差，
默认仍为 `interval`）。

分数本身的有效期：截面 IC 在 5/10/20/40/60/120/250 日持有期上是 0.074/0.090/0.115/0.153/0.177/0.195/0.230（全样本，`reports/signal_horizon/`，§23.66）——**不衰减**，是一个慢信号；5–10 日最弱，所以提高调仓频率只多付成本。趋势分量的 IC 全程为负（-0.03 ~ -0.09），但把 `trend_weight` 调到 0 并不会更好（纯低波平均 Sharpe 1.055 vs 默认 1.145，§23.67）：它承担的是过滤与稳定作用。

**但信号慢不等于持仓慢**（§23.74，`reports/holding_persistence/`）：8 只等权 + 20 日调仓的实测中位持有时长就是 20–26 个
交易日，每期换掉 37–48% 的名字（留存率 0.52–0.63），持有满一年的片段只占 0–0.8%，三段窗口分别只碰过 86/65/57 只股票；
96% 的成交额来自名字进出而非留存名字的再平衡。所以「低波核心」的执行现实是**月度轮动**，成本与容量都按这个节奏理解。

**把周期拉长呢？**（`reports/cadence_blend/`，§23.91）在混合口径下把调仓间隔从 20 日拉到 60 日，
三段 Sharpe 均值从 0.881 到 0.891（12 个配对格**全部含 0**），但年换手从 11.5x 降到 5.7x（−51%）。
所以它**不是收益杠杆，是成本工程选择**：published 成本下打平，成本更重时 60 日占优，
成本为零时 20 日占优。代价是 2019–2021 那段明显更差（−0.434，P=6%）。

## 组合与风控

- 等权买入选定名单，`build_portfolio` 依次应用：**可选的**基准趋势开关、
  波动率目标（按切换时点锁定一个缩放档位）、每票权重上限与总仓位上限。
- **基准趋势开关默认关闭**。11 个滚动样本外窗口显示它把总收益从 +74% 压到
  +4%、Sharpe 从 0.82 降到 0.15，因此不纳入默认配置；需要复现该实验时显式
  加 `--use-regime`（`build_portfolio(use_regime=True)`）。
- 波动率目标是默认开启的风险预算工具：Sharpe 略降（0.84→0.82），但最大回撤
  与非正态尾部更可控。
- **回撤熔断已实现但默认关闭**（`BacktestConfig.drawdown_stop=None`）。实测在
  本策略上全部有害：10%/15% 阈值把总收益打到 -6%~+103%，Sharpe 降到 -0.08~0.75，
  只换来 1-3pp 回撤改善。低波组合在调仓时已经在卖出下跌的标的，熔断等于在更差
  的价格上再卖一次。
- 波动率目标用已持仓组合的已实现波动估计，不使用未来数据。
- **beta 对冲是市场方向押注，不是稳健风控层**：2022–2026 单窗口里静态对冲
  35% 把 Sharpe 从 1.12 提到 1.29；但三窗口复核后，2019–2021 与 2024–2026
  的 ΔSharpe 分别是 -0.16 与 -0.18，只有 2022–2023 是 +0.56。12 个月 EWMA
  与 60 日滚动 beta 也没有一段稳定为正。默认不启用；复现：
  `scripts/run_hedge_panel.py --n-boot 3000`。

## 结论台账

所有结论的证据强度、置信度和“已被证伪的方向”集中记录在 `FINDINGS.md`。
对外引用任何收益数字前，先读那张表：低波因子本身是高置信度，但它的 IC 大头来自
**退市与规模通道**（§23.76：在册口径只有全池的三分之一），而**相对低波篮子的增量
超额是低置信度、且集中在 3 个月**。

## 模拟盘账本

`quant_system/paper.py` 与 `paper` 子命令把信号接到一个可执行的账本上，不需要券商接口：

- 账本是版本化 JSON，写入走临时文件 + rename，不会写坏。
- 目标股数按**当前权益**（现金 + 市值）计算，不是按初始资金。
- 卖出先于买入，卖出所得可用于买入；买入不超过可用现金 × (1 - 现金缓冲)。
- **不会超卖**（卖出股数不得超过持仓）、**不会透支**；任何越界直接报错而不是静默修正。
- 每笔成交记录佣金、印花税、过户费与已实现盈亏，可与券商流水逐行对账。
- `--reconcile` 输出 `reconciliation.csv`，只列出差异项。

成交文件只要求 `symbol, price, shares` 三列；`side` 可省略（未持仓则视为买入、
已持仓则视为卖出），券商导出的原始流水可以直接喂进来。缺列时会给出明确的
错误信息而不是 KeyError。不同已实现盈亏会在 `realized_pnl` 中单独记账。

它同样可以回放回测的成交，用来检查研究回测与运行账本是否一致
（`scripts/check_ledger_replay.py`，当前差异 `-0.00` 元）。

## 当前基线结果

> **先读这一条：单一收益数字不是策略结论。**
>
> 20 日调仓的“相位”由回测第一根 bar 决定，是任意选择。同一批股票、同一份
> 价格、同一套参数，只把相位平移 1 天，全样本收益就能从 +166.5% 掉到
> +47.5%（20 个相位的跨度 119pp，见 `RESEARCH_LOG.md` §23.21）。因此下表
> 的 `+149.5%` 是**某一个相位的实现**，不是稳健估计。

低波核心（`top_n=8, vol_window=60, trend_window=120, max_per_sector=2,

### 样本外结论与不确定度

walk-forward 固定参数（`top_n=8, vol_window=60, trend_window=120, max_per_sector=2,
rebalance_days=20`，年度重置，PIT 267 只，重建口径），三段独立样本外：

| 区间 | 累计收益 | Sharpe | 最大回撤 | Sharpe 95% 区间 | 回撤 95% 区间 |
|---|---:|---:|---:|---|---|
| 2019-07 .. 2021-12 | +43.84% | 1.048 | -16.19% | [-0.23, 2.32] | [-33.22%, -9.47%] |
| 2024-01 .. 2026-11 | +43.68% | 1.082 | -9.31% | [+0.01, 2.11] | [-23.18%, -7.31%] |
| 2022-01 .. 2023-12 | +35.50% | 1.198 | -21.37% | [-0.31, 2.68] | [-27.03%, -7.75%] |
| 2024–2026 相位中位 | +24.97% | 0.668 | — | — | — |
| 2024–2026 最差相位 | +9.13% | — | — | — | — |

**上面三行是相位 0 的读数**，而 §23.82 显示 offset 0 在 2022–2023 是 20 个相位里最好的
一格、在 2024–2026 位于 80 分位。所以这张表的正确读法是「某个日历交付了什么」，不是
「策略能交付什么」；后两行给出同一窗口的相位中位与最差相位。

三点必须一起读：

- **2019–2021 绝对收益为正，但跑输等权全池。** 该段 +43.84% / Sharpe 1.05 /
  -16.19%；相对等权全池的月度超额 -2.62pp（月均 -0.09%，t=-0.14），相对
  低波 1/3 篮子只有 +5.21pp（月均 +0.18%，t=0.26），且前三月份贡献了 368%。
- **2–3 年的样本外不足以证明 Sharpe 显著为正。** 上述区间的下界都贴着 0，
  这不妨碍策略可用（正 Alpha、beta≈0.38），但把 1.08 当成“已验证的 Sharpe”是错的。
- **回撤点估计偏乐观。** 同一批日收益换一种排列，2024–2026 的中位回撤是 -12.2%、
  2.5% 分位是 -23.2%。2022 年那种 -21% 的回撤，本来就在同一条分布的尾部里。
- **按可复现的 Sharpe（0.90）算，这段记录只有 56% 的检出力**（§23.89，`reports/power_recheck/`）：
  部署口径 7.14 年的自助法 95% 区间是 [0.098, 1.677]，80% 把握需要 **13.6 年**。所以
  “策略有效”目前是 suggestive，不是 established；把它读成“Sharpe 0.9 已获统计确认”是错的。
- **但“多接几个池子”不等于多一份证据**（§23.92，`reports/cross_pool/`）：把 267 只按行业切成六个
  互不重叠的池子各自跑，Sharpe 是 −1.378/−0.001/−0.122/0.671/0.609/0.707，等权合并只有 **0.094**，
  而全池 **1.269**。平均两两相关 0.333（等效独立池 2.2/6），但**独立没用——因为子池本身没有 alpha**。
  低波核心吃的是跨行业宽度；切窄了因子就失效。要提检出力，需要的是“另一个同样宽的横截面且溢价
  可迁移”，不是“一些不相关的小池子”。
- **宽度是一条连续斜坡，不是开关**（§23.93，`reports/cross_pool_random/`）：随机抽 60 / 120 / 267 只，
  Sharpe 中位 **0.391 / 0.824 / 1.269**——每翻一倍宽度约 +0.4。但 60 只时**仍有 95% 的抽样是正的**
  （行业池只有 50%），所以真正杀死行业池的是**集中**而不是窄。第二市场要有 **≥120 只**才划算：
  60 只的期望只有 0.39、p10 仅 0.059。

检出力可以直接算（`reports/power_study/`，§23.64）：真 Sharpe 1.0、年化波动 12% 时，3 年样本让 95% 区间排除 0 的概率只有 **6%**，6 年才 53%，80% 把握要 **9.3 年**（Sharpe 1.5 也要 5.8 年）。三段样本外合计 7.3 年，检出力约 65%——所以「三段都为正」是有信息量的证据，但离「被证明」还差两年左右，而且这 7.3 年并不独立。

参数比较用配对自助法（同一重采样日历，去掉行情运气）：

| 对比 | ΔSharpe | 95% 区间 | P(Δ>0) |
|---|---:|---|---:|
| `trend_window` 160 − 120（2024–2026） | +0.455 | [-0.000, +0.929] | 0.97 |
| `trend_window` 160 − 120（2022–2023） | **-0.454** | [-1.013, +0.092] | 0.05 |
| `trend_window` 160 − 120（2019–2021） | **+0.479** | [-0.418, +1.389] | 0.85 |
| `trend_window` 160 − 120（拼接 2022–2026） | +0.058 | [-0.342, +0.443] | 0.62 |
| `trend_window` 180 − 120（2024–2026） | +0.057 | [-0.457, +0.621] | 0.60 |

同一对参数在三段里**两正一负**（2019 +0.48、2022 -0.45、2024 +0.46），没有一段
显著，拼接后差异归零。2019–2021 的 +30pp 优势只来自 4 个月：删掉 2020-01/02/07
与 2021-07 之后，160 反而落后 26.6pp、Sharpe 低 0.48（§23.51）。所以 `trend_window`
是**市场状态旋钮**，不是可优化参数：120 是工程冻结的发布口径，不是“被验证的最优”。

参数邻域也做了同样的三窗口检查（§23.49，`reports/param_panel/`）：把
`top_n`(6/8/10/12)、`vol_window`(40/60/90)、`rebalance_days`(10/20/40)、
`max_per_sector`(1/2/3) 各动一格，10 个变体里 **9 个在至少一段跌破 Sharpe 0.95**，
`top_n=12` 让 2022–2023 从 +35.3% 掉到 +3.0%，`max_per_sector=1` 直接变成负夏普。
默认点是唯一三段都 ≥1.03 的格子。这不是“默认最优”的证明，而是“**换个点更容易
变差**”的证明：参数只冻结，不再优化。

能不能再加一个与低波正交的信号？做过一轮完整排查（`reports/factor_study/`）：
Amihud 非流动性在“剥掉低波后的偏 IC”上最漂亮（+0.060，t=8.9；在最平静的
30% 里是 +0.090，t=9.3），但把它按权重加进组合后 2022–2026 从 +94.75% 掉到
+13.9%（权重 0.3）乃至 -25.7%（权重 0.5），样本外同样是 +5.8% vs +35.5%。
原因是均值几乎不变、左尾翻倍（最差 20 日 -16% vs -8%），并且非流动性标的
大多处在停牌/涨跌停状态，成交笔数从 500+ 掉到 30+。12-1 动量同样稀释收益。
**结论：本轮没有找到可用的第二信号，默认配置不变。**

趋势过滤本身做过消融（`reports/trend_ablation/`、`reports/bootstrap_trend_ablation/`）：
完全关闭股票级 120 日均线过滤后，三段样本外收益从 +43.8% / +35.5% / +43.7%
掉到 +1.4% / +28.3% / +29.9%，所以它不是可删的保险层。把均线下方低波股用于
补足空位，三段 ΔSharpe 只有 +0.034 / -0.007 / +0.005，全部是噪声，默认补位
保持关闭。

超额的来源做过两层归因（Brinson-Fachler，逐月）。第一层用等权全池做基准：
行业配置项约等于 0（2022 段 -0.2%，2024 段 +2.5%），74%–84% 来自行业内选股——
所以它不是伪装成低波的行业轮动。第二层把基准换成**低波 1/3 等权篮子**
（策略真正的对手），结论收缩很多：

| 区间 | vs 等权全池 | vs 低波 1/3 篮子 | 月均超额 / t 值 | 月度胜率 |
|---|---:|---:|---:|---:|
| 2019–2021 | **-2.62pp** | +5.21pp | +0.18% / 0.26 | 52% |
| 2022–2023 | +71.4pp | +55.5pp | +2.52% / 1.93 | 59% |
| 2024–2026 | +37.6pp | **+5.5pp** | +0.17% / 0.29 | 48% |
| 2022–2026 | +115.1pp | +62.6pp | +1.12% / 1.77 | 54% |

也就是说：2024–2026 段的超额**基本就是低波因子本身**（同期低波篮子 +33.0%，
全池 +0.9%）；2019–2021 段甚至跑输等权全池，相对低波篮子的 +5.21pp 也不
显著，且其中 368% 来自最好的 3 个月。归因修复了“停牌持仓被当成现金”的口径
后，2019–2021 的平均月末现金是 13.3%，另有 6.0% 的停牌持仓；跑输的主因仍是
科技低配导致的选股项 -5.56%，不是现金。只有 2022–2023 段能称为“真选股”，
所以对外不能说这套策略在每个行情都跑赢基准。
全样本的超额集中在下行月（篮子下跌月 +2.31%/月，上涨月 -0.08%/月），
这是防守型策略的形状，别指望它在上涨行情里跑赢低波 ETF。

现在 `exposure` 只统计测试窗口，旧口径保留为 `exposure_full_history`。

### 调仓日历：一个可复现性修复

20 日调仓原本从**回测第一根 bar** 开始计数，所以窗口平移一天，所有调仓日
一起平移，结果可以从 +166% 掉到 +47%。`--rebalance-reset year` 改为每年
1 月第一个交易日重新计数，从第一个完整年份起调仓日只由市场日历决定：

| 起点平移（bar） | 0 | 1 | 2 | 3 | 5 | 10 | 20 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 总收益 | 75.6% | 77.0% | 77.9% | 77.0% | 81.2% | 73.7% | 66.0% |

收益跨度从 **119pp 降到 15.2pp**。但请注意：它修的是**可复现性**，不是收益。
年内 20 个 offset 仍然差 100pp（+35% 到 +135%），所以报告仍必须给
median/worst/best。两个措施要一起用：

2020 年单年 -27.7pp 是主要拖累。140 只退市股中有 54 只曾被持有，合计实现盈亏
+13.7 万元（其中 28 只为正、26 只为负）。这 140 只退市股中，没有一只被持有到最后一根
bar，**实际退市强制清算为 0 次**；因此 -12.1pp 来自可选集扩大后的路径差异，
而非退市清算亏损。但真实
退市样本**仍不足以**覆盖“低波陷阱”型极端风险。该 -12.1pp 是**全样本的事后测量**，
不是可交易优势；严格配对的滚动样本外并没有稳定复现，详见下一段。

**同一套滚动样本外下的对照**（`reports/pit_walkforward/`，504/126/10，固定参数，
11 个不重叠测试窗口，严格配对 262 只）：PIT 池 +102.39% / Sharpe 1.0278 /
回撤 -16.10%，存续池 +78.88% / 0.8589 / -16.68%。PIT 有 9/11 个窗口正收益，
但只有 6/11 个窗口收益优于存续池（Sharpe 为 8/11），逐窗收益差均值 +1.25pp、
标准差 4.86pp、t-like 0.854，离散度约为均值的四倍；路径差异主要来自新增个股
而非参数选择。因此不能据此宣称 PIT 池“更优”，只能说全样本的 -12.1pp 偏差
在滚动样本外**没有被稳定复现**，方向仍不确定。报告保留两组结果与逐窗口
对照，不做择优引用。

**跨策略对比**（`reports/runs/compare_*`，同一窗口与成本）：`low_volatility`
+145.1% / Sharpe 1.01 / 回撤 -13.9%，明显优于 breakout（+93.2% / 0.66）、
momentum（+75.0% / 0.56）与 multi_factor（+29.6% / 0.31）。

**稳健性结论**（`reports/robustness/`、`reports/stress/`）：

- 21 个单参数邻域 20 个仍盈利（`trend_window=150` 是孤立空洞）——**这条来自旧归档股票池，和 §23.49 的 PIT 三窗口结论不一致，只能当历史记录**。
- PIT 口径下参数曲面其实很陡：沿 `top_n` / `vol_window` / `rebalance_days` /
  `max_per_sector` 各走一格，10 个变体有 9 个在某一段 Sharpe 跌破 0.95，
  默认点（8 只 / 60 日）是唯一三段都 ≥1.03 的格子。详见 §23.49、`reports/param_panel/`。
- 归档口径下去掉表现最好的 10 只股票后总收益 +134.8%（vs +145.9%），Sharpe 0.86；
  该压力测试尚未在当前分类上重跑。
- 信号延迟 3 天仍 +129.5%，延迟 20 天仍 +98.7%。
- 40 次随机抽取 80% 股票池，全部跑赢指数，Sharpe 5% 分位 0.60。

**成本与容量**：当前口径下 100 万从未触及 10% ADV 上限（917 笔 0 次），
所以容量不是瓶颈；5000 万反而比 100 万高 5.3pp。但收益随资金单调上升并收敛
（10 万 +124.70% → 100 万 +149.48% → 1 亿 +155.42%），机制是**整手取整**：
高价股一手就超过目标金额，小账户被系统性低配（10 万平均仓位仅 75.4%，
100 万 81.7%，1 亿 83.0%）。因此 8 只等权策略不适合 10 万级账户。
旧归档的“5000 万 -10.3pp”来自含前视 ADV 的旧口径，不应再引用。
见 `reports/lot_quantization/`、`reports/adv_lookahead/`，详见 §23.17。

**成本敏感度**（`reports/cost_panel/`，§23.55）：同一组权重只改撮合成本，
把佣金翻倍（5bp）、滑点加到 20bp、再打开 60bps·√(参与率) 的冲击项，三段
Sharpe 仍是 **1.075 / 1.032 / 0.922**（累计 +41.0% / +30.5% / +36.2%）。
更温和的两档（佣金翻倍、40bp 冲击）只损失 0.005–0.058 Sharpe。所以结论不是
零成本幻觉；但这条**只在 100 万资金**下成立，冲击项几乎不起作用。
同一套四档成本再跑一遍 12% 目标（`reports/cost_target_interaction/`，§23.63）：12% 在 12/12 个（情景 × 窗口）格子里回撤都更浅——harsh 下 2022–2023 是 -16.3% vs -22.2%——而 12 个 ΔSharpe 区间全部含 0，符号由窗口而非成本决定。所以提高成本假设不会让 12% 变成更优选择，也不会推翻它「降风险」的定位。

每笔成本的分解（`reports/cost_decomposition/`，§23.70）：published 情景单边 10.2bp（买 7.6 / 卖 12.7，差的 5bp 是印花税），impact40 的冲击项只有 0.74bp，harsh 的 28.7bp 里冲击仅 1.06bp——**harsh 压的是固定成本假设，不是冲击模型**。100 万本金这一档冲击可以忽略，放大到 ADV 的 5% 以上要改用 `reports/capacity_v2/` 的曲线。

**容量曲线**（`reports/capacity_curve/`，§23.72）：同一套 18% 配置在 100 万到 20 亿初始资金下跑 2024-01 .. 2026-11，参与上限 20% ADV。成交量上限几乎咬不到——平均总仓位 0.927→0.932、1 亿以内权重漂移稳定在 0.045、Sharpe 从 1.039 只滑到 1.021；真正压低容量的是冲击成本：叠加 40bp 平方根冲击后 Sharpe 从 1.034（100 万）单调滑到 0.844（10 亿）。所以规模决策的变量不是「能装多少钱」，而是「冲击系数估得准不准」，对照见 `reports/capacity_curve_impact40/`。

**要不要按混合口径重算容量**（`reports/capacity_blend/`，§23.84）：要，而且结论更好看。
混合换手 15.1x（单相位 13.4–13.6x），但执行漂移只有 **0.035**（单相位 0.045–0.058）——
它持有 20 套篮子的并集、单笔更小，截断更少。40bp 冲击下混合从 100 万到 20 亿只掉 **0.071**
Sharpe（1.034→0.849 的单相位掉 0.185），规模敏感度只有 38%。所以 §23.72 的“10 亿”上限对
混合依然成立且更安全；但要记住混合的绝对水平低于 phase 0 是因为 phase 0 是 80 分位相位，
正确对照是相位中位 0.668——混合在 40bp 下仍有 0.745。

## 已知限制

- 默认股票池仍是“当前仍上市”的 128 只（有效 122 只），存在幸存者偏差。
  同窗全样本测得描述性差异 -12.1pp，但严格配对滚动样本外未稳定复现；
  合成低波退市陷阱上界显示可能吃掉更多收益。
- 已实现的 point-in-time 池（`reports/point_in_time/`）尚未作为默认口径。
  268 只的价格与重建数据已完整（2026-11-07 复核），但**行业分类是静态的**，
  退市标的没有历史行业快照；把它设为默认会让行业上限在旧年份失真。
- 行业分类为静态研究映射，不是历史时点分类。
- **可交易性**（`reports/tradability/`，§23.75）：PIT 池的横截面宽度在样本内从 251 只
  降到 128 只——退市股在最后一根真实 bar 之后退出横截面，这是 PIT 的正确行为，但
  意味着“267 只”只在 2019–2020 成立。2019–2021 窗口有 **41.5% 的交易日存在冻结仓位**
  （停牌按最后收盘计价、日收益恒为 0，平均占账面权重 6.85%、最高 26.0%）。这笔冻结
  仓位等价于现金，收益与波动同时按比例收缩，**不改变 Sharpe**，但意味着该段平均
  敞口只有 0.880（2024–2026 为 0.927，§23.74）；2022 年之后冻结敞口为 0。
  最长一例是 `sh600145`：持仓期间 242 个交易日没有 K 线。
- 腾讯接口有频率限制（HTTP 501），下载器会重试并支持断点续传。
- 前复权价格锚定当前，跨会话全量刷新时会有整体缩放。
- 研究窗口起点 2019-06-05 是 `--count 1800` 的下载截断点，不是真实上市时点。
  尝试下载 4000 根时，腾讯 qfq 返回负价（如 `sh600519` 4000 根中 1492 根非正价），
  hfq 接口返回 HTTP 501，因此**2019 年之前的长样本结论无法验证**。
  加载器与加载函数已拒绝非正价格，避免坏数据污染回测。
- 未建模盘中打开涨跌停、集合竞价、冲击成本的非线性部分。
- 行业分类是静态映射；`audit` 会拒绝“其他”类别，但不会还原历史行业变更。
  2026-11-06 的审计把 `601012` 从“其他”补为“能源”，基线因此从归档的 +145.93%
  变为 +149.48%。这不是策略改进，而是行业上限下的选股路径变化；
  见 `RESEARCH_LOG.md` §21.14。
- 缓存审计只能证明“文件与下载元数据一致”，不能证明“元数据请求到的就是完整历史”。
  `--count 1800` 截断在元数据里是合法状态，仍需结合 §20 的接口限制理解。

**完全留出段反例**：2025-11-05 之后的约 12 个月里，8/2 为 +6.15% / Sharpe 0.65，
6/2 为 +2.73% / 0.33（沪深 300 -11.10%）。这段完全不参与宽度选择，却给出
相反排序，因此 6/2 不是稳定占优的配置；默认保持 8/2。产物见
`reports/heldout_width/`，详见 `RESEARCH_LOG.md` §23.6.2。

**排名缓冲的过拟合检验**：§23.3 曾报告 6/2 下 `buffer_rank=2.0` 的全样本最优
（+230.9% / 1.168）。严格复核后它在 504/126/10 滚动样本外只有 +126.16% / 1.149，
收益略低于默认 1.5 的 +126.47%，逐窗口配对均值 -0.04pp（仅 4/11 胜）；
在 8/2 上更差（+71.20%，回撤 -20.04%，正收益窗口 7/11）。因此缓冲保持 1.5，
该全样本最优点被证伪。产物见 `reports/buffer_rank/`，详见 §23.8。

**行业权重预算**：把行业上限从“只数”换成“权重”（8/2 压到 20%/15%，6/2 压到 25%）
确实降低波动与回撤，但每个上限档都配了同等总仓位的对照后，逐窗口配对全部为负
（-0.38pp / -0.60pp / -0.72pp，胜率 4/11、4/11、3/11）。也就是说改善来自
“仓位更低”，不是“行业更分散”。需要低回撤应直接调 `target_annual_vol`。
产物见 `reports/sector_weight_budget/`，详见 §23.9。

**低波是否只是流动性/规模代理**：不是。20 日横截面上，低波与 Amihud 非流动性
的秩相关仅 +0.020，互相正交后仍有独立 IC（低波 +0.0180、Amihud +0.0189）；
但规模才是低波的近亲（剔除规模后低波 20 日 IC 只剩 0.0036）。**不过 §23.77 的成分分解
改写了这半条的读法**：Amihud 全池 IC +0.0664（t=11.3）在两个成员口径内部**都是负的**
（仍在册 -0.0109、t=-2.63；最终退市 -0.0050），它测的是“退市群 vs 在册群”的组间对比，
不是一个池内信号——偏 IC 只是把同一条组间通道投影到低波之外。组合层面把
30% 权重给流动性反而变差：6/2 +93.69%（纯低波 +126.47%），8/2 正收益窗口
从 10/11 降到 6/11。因子有信息 ≠ 组合能变现。产物见 `reports/liquidity_factor/`，
详见 §23.10。

**低波 IC 的大头来自退市与规模，不是“低波股会赢”**：把 PIT 池按“今天仍在册 / 最终退市”
拆开算 20 日横截面 IC，全池 +0.0987 里最终退市那批贡献 +0.1503（t=27.8），仍在册那批只有
+0.0309（t=4.7），5/10/20/60 日四个 horizon 上相差 3.8–5.3 倍；而把每天横截面抽到 N=128
的宽度匹配几乎不改变 IC（§23.76），所以“池子变窄”不是 IC 上升的原因。这与上一条
“剔除规模后只剩 0.0036”是同一件事：低波分主要在识别“会死 / 很小”的股票。说“低波因子有效”
时应同时给出全池与在册两个数，组合层的增量研究应以在册口径的 +0.031 为基准。
产物见 `reports/breadth_ic/`，详见 §23.76。

**这套书的钱到底从哪来**（`reports/pnl_cohorts/`，§23.79）：用三个归档窗口的成交拆已实现
盈亏，2019–2021 有 **63%**、2022–2023 有 **61%** 来自“今天已退市”的那批股票（前者分布型，
41 只里 22 只赚；后者脆弱，3 只占 87%）；2024–2026 只剩 1 只且亏损，**105.6% 的盈亏来自
仍在册群**。全部卖出标签都是 `rebalance`，退市强制清算从未触发——书是在这些票活着的时候
买入、死之前卖出的，不是“躲开了”。这意味着长期收益里有一部分来自一个**随池子收缩而消失**
的来源；向前看的基准应取**部署口径**（见文首「引用口径」表），而不是把七年 CAGR 线性外推。
（这句原先写的是 +43.68% / 1.08，§23.82 起作废：那是相位 0 的读数，20 个相位的
中位只有 +24.97% / 0.668。）

**但这不是“凑不出 8 只”**（`reports/selection_slack/`，§23.80）：91 次调仓全部满配 8 只，
可选名数中位 85、最少 26，每行业 2 只上限一次都没咬住（可容纳名数最少 9，`cap_binds` 0/91）。
可选/可交易 八年稳定在 36%–53%，所以池子缩水是直接传导，不是阈值变严。规则一直能执行到底——
变化的是**凑出来的这 8 只是从哪个池子里挑的**。

**再往下一层看，挑出来的是谁变了**（`reports/selection_character/`，§23.81）：波动筛选没有退化
——选中标的中位波动 21.98%→18.56%，在池中的波动百分位反而 88.8%→**92.5%**；但宇宙换了：
日成交额中位 2.88 亿→**10.66 亿**、价格中位 5.76→**18.54**、退市口径占比 32.6%→**0.3%**。
所以这个策略今天的正确名字是**大盘低波**，不是“低波核心”。

**但这些窗口数字是「日历恰好合适」的量级**（`reports/phase_recheck/`，§23.82）：20 个合法调仓
相位在每段的收益跨度是 32–47pp，而 offset 0（当前默认）在 2022–2023 是**20 个相位里最好的
一格**、在 2024–2026 位于 80 分位。按相位中位，2022–2023 是 +18.12%（最差 +3.00%）、
2024–2026 是 **+24.97% / Sharpe 0.668**（最差 +9.13%）。年度重置（§23.23）只把跨度收窄了一点
——两段收窄、2022–2023 反而放大——**没有消掉相位彩票**。引用任何一段的收益时，请同时给出
相位中位与最差相位。

**向前基准的最终口径**（`reports/phase_blend/`，§23.83）：同时持有 20 个相位、各 1/20 权重。
混合波动 12.58% / 12.82% / 12.49%，三段都**低于任何一个单相位**；2024–2026 给出
**+27.72% / Sharpe 0.780 / 最大回撤 −13.68%**，代价是约 10% 更多换手。这个数字可以重复——
只要规则不变，它不取决于你从哪天开始数。三次修订到此收口：+43.68%（相位 0，靠运气）→
+24.97%（相位中位，靠“恰好挑中位那一天”）→ **+27.72%（混合，可重复）**。

**部署配置到此定型**（`reports/voltarget_blend/`，§23.85）：**混合 + 12% 目标波动**。
2024–2026 为 **+26.29% / Sharpe 0.800 / 最大回撤 −12.10%**；相对 18% 只少 1.4pp 收益，换来
1.6pp 更浅回撤与更高 Sharpe。**10% 被 12% 严格支配**（三段回撤几乎相同、各少赚 6.3/2.8/3.1pp），
15% 与 18% 在近段几乎重合（自然波动已接近 12.3%），所以真正的选择只有 12% vs 18%。
12% 在三段里的回撤都比 18% 浅，而 ΔSharpe 九格全部含 0——它是**风险预算的选择**，不是 Sharpe 改进。
