所以更准确的名字是：在最平静的 8 只里剔除跌破趋势的那些，而不是「低波打分 + 趋势确认」——后者会让人以为打分在做主要工作。

这台机器值在哪（这比「值多少」更重要）：把低波分换成随机分、其余约束全不变时， Sharpe 从 1.143 掉到中位 0.116（随机 p95 只有 0.459，发布策略在第 100 百分位，§23.102）。 但换成「最自然的替代品」就不一样了：在册 128 只里直接选最平静的 8 只、不加趋势过滤与行业上限（§23.109）——三段 ΔSharpe 只有 -1.11 / +0.04，6 格中 0 格显著，而它的换手只有发布策略的 1/3.9。 所以「打分有用」的准确版本是：相对随机有用；相对最自然的替代品，只有趋势过滤在 2019–2021 那种行情里明显值钱。 另外，低波分在仍在册名字上的池内 IC 只有 +0.031（§23.77），相对低波 1/3 篮子的增量超额也只有 +13.4%/年、t=1.77（§23.40）—— 这两条针对的是「在桶里精挑」，而上一段的正面结果针对的是「待在桶里」。
